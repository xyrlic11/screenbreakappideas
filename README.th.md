# Blink

โปรแกรมเตือนพักสายตาบน Windows ตามกติกา 20-20-20 — ทุก 20 นาทีที่จ้องจอ
ให้มองไกล 20 ฟุต นาน 20 วินาที

จุดที่ต่างจากแอปแนวเดียวกันคือ **ตอนที่คุณไม่อยากพัก** Blink ไม่ห้ามคุณ
แต่ทุกทางออกมีต้นทุน และต้นทุนนั้นมองเห็นได้

> English: [README.md](README.md)

---

## วิธีรัน

```bash
python -m venv .venv && .venv\Scripts\pip install -r requirements.txt
```

```bash
.venv\Scripts\python -m blink
```

| Flag | ทำอะไร |
|---|---|
| `--tray` | เริ่มแบบอยู่ใน tray ไม่เปิดหน้าต่าง (autostart ใช้อันนี้) |
| `--debug` | ย่อทุกช่วงเวลา 20 นาทีเหลือ 20 วินาที ทดสอบครบรอบใน 30 วินาที |
| `--simulate 8h` | จำลองทั้งวันผ่าน engine แล้วพิมพ์ timeline ไม่เปิดหน้าต่าง ไม่ใช้ Qt |

### แพ็คเป็นแอป

```bash
python tools/build.py
```

สร้าง `assets/blink.ico` ใหม่จากโค้ดชุดเดียวกับที่วาดไอคอน tray แล้วรัน
PyInstaller ผลลัพธ์อยู่ที่ `dist/Blink/Blink.exe` ขนาดราว 100 MB
(รวม Qt) ยังไม่ได้เซ็นชื่อดิจิทัล SmartScreen จะเตือนตอนคนอื่นเปิดครั้งแรก
ซึ่งต้องมี code signing certificate ถึงจะแก้ได้

## หน้าต่างแอป

4 หน้า อยู่หลัง sidebar แบบ Fluent

- **หน้าหลัก** — วงแหวนนับถอยหลังถึงรอบพักถัดไป และตัวเลขของวันนี้
- **สถิติ** — อัตราพักครบ, streak, และกราฟ 7 วันว่าพักครบเทียบกับข้าม
- **ตั้งค่า** — ทุกค่าที่สำคัญ มีปุ่มให้กด ไม่ต้องแก้ JSON
- **เกี่ยวกับ** — เวอร์ชัน ความเป็นส่วนตัว และที่อยู่ของไฟล์

แอปเดินตามระบบ: อ่านสี accent และโหมดสว่าง/มืดจาก registry, ใช้พื้นหลัง
Mica, แถบหัวหน้าต่างสีเข้ม และมุมโค้งตามที่ Windows รองรับ ถ้าเครื่องไม่รองรับ
ก็ถอยไปเป็นหน้าต่างทึบธรรมดา ปิดหน้าต่างแล้วแอปยังอยู่ใน tray
การออกจริงต้องสั่งจากเมนู tray

ตัวอักษรละตินใช้ Segoe UI Variable ส่วนไทยตกไปที่ Leelawadee UI
และเพิ่ม line-height เป็น 150% เพราะสระบน/ล่างกับวรรณยุกต์ของไทยจะชนกัน
ถ้าใช้ค่า default

## หลักการทำงาน

6 ชั้น ไหลทางเดียว ทุก 1 วินาที: อ่าน sensor → อัปเดต state → ถาม policy →
สั่ง UI

```
Sensors  ──►  State machine  ──►  Policy  ──►  Commands  ──►  UI
idle time     นับเวลาอยู่ไหม     ถึงเวลาพัก      show_toast    overlay
lock state    นับไปเท่าไรแล้ว    หรือยัง         start_break   toast
sleep gaps                                       lock_...      window
```

UI ไม่นับเวลาเอง ถามมันว่าอีกกี่นาทีจะถึงเวลาพัก มันตอบไม่ได้ —
มันรู้แค่ว่าถูกสั่งให้วาดอะไรล่าสุด ข้อจำกัดนี้แหละที่ทำให้เทสต์ได้จริง

### การเตือนแบบไล่ระดับ

การถูกขัดจังหวะตอนกำลังพิมพ์คือเหตุผลอันดับหนึ่งที่คนถอนแอปแนวนี้

| เมื่อไร | อะไรเกิดขึ้น | รบกวนแค่ไหน |
|---|---|---|
| ก่อน 2 นาที | Toast มุมขวาล่าง | ต่ำมาก ปิดเองได้ ไม่แย่ง focus |
| ก่อน 10 วินาที | ขอบจอค่อยๆ เรืองแสง | เห็นด้วยหางตา คลิกทะลุได้ |
| ถึงเวลา | Overlay เต็มจอ | บังคับ |

### Grace period

ถ้าครบเวลาตอนกำลังพิมพ์รัวอยู่ overlay จะรอจังหวะที่คุณหยุดพิมพ์ —
เลื่อนได้สูงสุด 2 นาที แล้วเด้งแน่นอน ส่วนคนที่แค่นั่งอ่านอยู่เฉยๆ
เด้งทันที เพราะไม่มีอะไรต้องถนอม

### เลือกได้ว่าจะให้บังคับแค่ไหน

นี่คือสิ่งเดียวที่คุณกำหนดได้จริงๆ ว่าแอปจะดุแค่ไหน ตั้งแยกกันได้ระหว่าง
พักสายตากับพักยาว

| โหมด | เกิดอะไรขึ้น | ข้ามยังไง |
|---|---|---|
| **บังคับเต็มจอ** | เต็มจอ บังทุกอย่าง (ค่าเริ่มต้น) | กดปุ่มข้ามค้าง 5 วินาที |
| **แค่เตือน** | การ์ดมุมจอ มีตัวนับถอยหลังและกิจกรรมเดียวกัน ไม่แย่ง focus ไม่บังอะไร พิมพ์งานต่อได้เลย | คลิกที่การ์ด |
| **ล็อคหน้าจอจริง** | `LockWorkStation()` มีเฉพาะพักยาว | ปลดล็อคก่อนเวลา — บันทึกเป็น skipped |

โหมด "แค่เตือน" ไม่ใช่ของถูกลด — พักครบในโหมดนี้ก็นับเป็นพักครบเหมือนกัน
แต่ฐานข้อมูลบันทึกไว้ว่าแต่ละรอบใช้โหมดไหน สองอย่างนี้จะได้ไม่ปนกันเงียบๆ

ถ้าตั้งพักยาวเป็น "แค่เตือน" การนับถอยหลัง 60 วินาทีจะถูกข้ามไปด้วย
เพราะการนับถอยหลังมีไว้ให้คุณเซฟงานก่อนจอหาย — การ์ดมุมจอไม่ได้เอาอะไรไป
เตือนล่วงหน้าก็เท่ากับจู้จี้เปล่าๆ

### หน้าจอพัก

5 กิจกรรม สุ่มสลับ ไม่ซ้ำอันเดิมติดกัน จอดำเปล่าๆ ไม่ใช่การพักสายตา
เพราะคนจะนั่งจ้องจอดำต่อ ทุกกิจกรรมจึงบังคับให้ตาทำสิ่งที่ทำไม่ได้ตอนอ่านจอ

| กิจกรรม | ให้ทำอะไร | ใช้กับ |
|---|---|---|
| มองไกลๆ | เปลี่ยนระยะโฟกัส วงกลมหดหายไป ไม่มีอะไรให้อ่าน | ทั้งคู่ |
| มองตามจุด | ใช้ลูกตาตามจุดจากขอบหนึ่งไปอีกขอบ ไม่หันหัว | ทั้งคู่ |
| กระพริบตาช้าๆ | หลับสนิทตามจังหวะเปลือกตา — จ้องจอทำให้กระพริบน้อยลงครึ่งหนึ่ง | ทั้งคู่ |
| หายใจ 4-7-8 | หนึ่งรอบ 19 วินาที จึงใส่ได้แค่ในพักยาว | พักยาว |
| ยืดคอและไหล่ | ทำตามหน้าปัด 4 ท่า | พักยาว |

Overlay ครอบ `screen.geometry()` ไม่ใช่ `availableGeometry()` — taskbar
โดนบังไปด้วย ไม่งั้น badge Discord เด้งอยู่มุมจอก็ทำให้การพักเสียเปล่า
ชดเชยด้วยนาฬิกาจริงมุมขวาบน และกด Esc ไม่มีผลอะไร

### ทางออกทุกทางมีต้นทุน

| | ปุ่ม Skip | ปุ่มฉุกเฉิน |
|---|---|---|
| ตำแหน่ง | มุมล่างขวา | มุมล่างซ้าย คนละฝั่ง กดพลาดยาก |
| ต้นทุน | กดค้าง 5 วินาที | ไม่มี กดครั้งเดียวปิดเลย |
| บันทึกเป็น | `skipped` | `emergency` |

ปุ่มฉุกเฉิน **จงใจ** ให้ไม่มีต้นทุน เพราะทางหนีที่คนกลัวจะกดคือทางหนีที่คน
จะหาวิธีอ้อม แล้วระบบต้นทุนทั้งหมดก็กลายเป็นแค่ฉากหน้า —
เปลี่ยนเป็นบันทึกไว้แล้วโชว์ในหน้าสถิติแทน

คีย์ลัด `Ctrl+Alt+Shift+Esc` ทำงานเหมือนปุ่มฉุกเฉิน เผื่อเมาส์ใช้ไม่ได้
หรือ overlay ค้าง

### พักยาวคือที่เดียวที่ล็อคจอจริง

| | ทุก | นาน | วิธีบังคับ |
|---|---|---|---|
| พักสั้น (สายตา) | 20 นาที | 20 วินาที | Overlay |
| พักยาว (ร่างกาย) | 2 ชั่วโมง | 5 นาที | `LockWorkStation()` ถ้าเลือกไว้ |

ล็อคจอเพื่อพัก 20 วินาที = เสียเวลาพิมพ์รหัสผ่านนานพอๆ กับเวลาพัก ไร้สาระ
เลยไม่มีตัวเลือกนี้ให้พักสายตาเลย แต่ 5 นาทีคือต้นทุนที่สมเหตุสมผล
และบังคับให้ลุกจากเก้าอี้จริงๆ

การล็อคจริง **ไม่ใช่ค่าเริ่มต้น** ค่าตั้งต้นคือพักยาวขึ้น overlay 5 นาที
พร้อมนับถอยหลัง 60 วินาทีก่อน และปุ่มเลื่อน 2 ครั้ง — หน้าเตือนนั้นเป็น
แผงลอย ไม่ใช่เต็มจอ เพราะมันกำลังบอกให้คุณเซฟงาน จึงต้องไม่บังงานที่ต้องเซฟ

### อะไรทำให้หยุดนับ

- ไม่แตะอะไรไม่ถึง 1 นาที ยังนับเป็นเวลาจ้องจอ — อ่านหน้าเว็บโดยไม่ขยับเมาส์
  คือเคสที่แอปนี้มีไว้เพื่อจับพอดี
- เกิน 1 นาที หยุดนับ
- เกิน 5 นาที รีเซ็ตตัวนับ ถือว่าพักสายตาจริง
- จอล็อค หยุดนับทันที แต่รีเซ็ตต่อเมื่อล็อคนานเท่ากับเกณฑ์ลุกไปพัก
  — กด Win+L วินาทีเดียวไม่ใช่การพัก และ UAC prompt ก็ส่งสัญญาณเดียวกัน
- เครื่อง sleep/hibernate ตรวจจากช่องโหว่ใน tick stream ไม่ต้องใช้ power API
  ถูกกว่าและครอบคลุมเคสอื่นด้วย เช่น เวลาเครื่องเปลี่ยน หรือโดน debugger หยุด

## ความเป็นส่วนตัว

- **ไม่ใช้ keyboard hook** ใช้ `GetLastInputInfo` ซึ่งบอกแค่ว่า
  *เมื่อไร* ที่มี input ไม่เคยรู้ว่า *กดปุ่มอะไร*
- **ไม่ต่อเน็ต** ไม่มีโค้ดเปิด socket สักบรรทัดใน repo นี้
- **ไม่ต้องรัน admin** autostart เป็นแค่ค่าใน `Run` key ของผู้ใช้เอง
- **ไม่เก็บอะไรที่ระบุตัวตนได้** ตารางประวัติเก็บแค่ว่าพักรอบนั้นถึงเวลาเมื่อไร
  คุณทำอะไรกับมัน และจ้องจอมานานเท่าไร ไม่มีชื่อหน้าต่าง ไม่มีชื่อ process

## เทสต์

```bash
.venv\Scripts\python -m pytest
```

`blink/core/` import แค่ stdlib — ไม่มี Qt ไม่มี Win32 และไม่เคยอ่านนาฬิกา
เวลาและค่า sensor ถูกส่งเข้ามาเป็น parameter ทั้งหมด
เวลาจ้องจอ 8 ชั่วโมงจำลองเสร็จใน **0.27 วินาที**

## สิ่งที่ยังไม่ได้ทำ

ระบบหนี้สายตา (Eye Debt), whitelist/DND สำหรับตอนประชุมหรือพรีเซนต์,
ตรวจเสียงและ active window, ประวัติสถิติยาวกว่า 7 วัน, installer

จุดต่อของ Eye Debt เตรียมไว้แล้ว: ความยาวการพักมาจาก
`PolicyEngine._next_break_sec()` ซึ่งเป็นบรรทัดเดียวที่ต้องแก้
